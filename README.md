Bienvenue dans ce **README** récapitulatif ! ## 🦊 2. Extensions Firefox (Nostalgie & Rétro-Interface)

Ces modules complémentaires pour le navigateur Mozilla Firefox permettent de restaurer les anciens designs ou comportements de sites web populaires.

### 🔍 Recherche & Encyclopédie
* **[Old Google](https://addons.mozilla.org/en-US/firefox/addon/old-google/)** : Permet de retrouver l'apparence classique et épurée des pages de recherche Google d'antan, sans les bannières publicitaires et lourdeurs modernes.
* **[Old Google Logos and Icons](https://addons.mozilla.org/en-US/firefox/addon/old-google-logos-and-icons/)** : Remplace les logos et icônes actuels de Google par les versions historiques (par exemple, les logos colorés en relief des années 2000/2010).
* **[Old Wiki](https://addons.mozilla.org/en-US/firefox/addon/old-wiki/)** : Restaure l'ancienne mise en page ou l'apparence classique de Wikipédia pour une lecture plus simple et nostalgique.

### 🎮 Gaming & Communautés
* **[Old Roblox Server List](https://addons.mozilla.org/en-US/firefox/addon/restore-old-roblox-server-list/)** : Restaure l'ancienne liste des serveurs de Roblox, idéale pour les nostalgiques de l'interface classique du jeu.
* **[Old Roblox Logo](https://addons.mozilla.org/en-US/firefox/addon/old-roblox-logo/)** : Remplace le logo moderne de Roblox par l'emblématique logo rouge penché ou les anciennes identités visuelles de la plateforme.

### 💬 Réseaux Sociaux & Actualités
* **[Old Twitch](https://addons.mozilla.org/en-US/firefox/addon/oldtwitch/)** : Permet de retrouver l'ancienne interface ou des éléments classiques de Twitch, évitant le design lourd actuel.

* **[Old Reddit Redirect](https://addons.mozilla.org/en-US/firefox/addon/old-reddit-redirect/)** : Redirige automatiquement toutes les pages de Reddit vers l'interface classique (`old.reddit.com`), beaucoup plus rapide et lisible que le design moderne.
* **[Old Twitter](https://addons.mozilla.org/en-US/firefox/addon/old-twitter/)** : Permet de retrouver l'interface classique de Twitter (type design 2015 ou antérieur) pour fuir les refontes récentes.

## 🚀 Utilisation & Installation

1. **Pour les sites web** : Cliquez simplement sur les liens pour explorer les interfaces d'archive ou les recréations en ligne.
2. **Pour les extensions Firefox** : 
   - Cliquez sur les liens des extensions Firefox ci-dessus.
   - Cliquez sur **"Ajouter à Firefox"** (Add to Firefox).
   - Profitez immédiatement de vos services préférés avec leur look rétro !
